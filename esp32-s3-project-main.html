Result Designed a 4-layer ESP32-S3 dev board in KiCad 9 — USB-C, ENS210 sensor, WS2812B RGB LED, impedance-controlled USB traces — 0 DRC errors, manufactured at JLCPCB.

I wanted a dev board I'd actually designed myself — not another module I just plugged in. Went 4-layer in KiCad because a solid GND plane directly under the RF module matters for EMI, and I needed impedance control for the USB traces — neither of those work reliably on 2 layers. The USB-C CC resistors nearly broke me — turns out without 5.1 kΩ on both CC pins, USB-C chargers simply don't deliver power. Boards came back from JLCPCB and actually worked first try — USB enumerated immediately and the temperature sensor responded on the first I²C scan — which honestly surprised me.

What I Learned
  • Impedance control isn't just about the traces — you have to pick a stack-up the fab actually supports. The JLCPCB JLC04161H-3313 stackup publishes its prepreg parameters, so calculating the 90Ω differential width for USB D± was straightforward. If I'd picked a stackup without published Dk values, I'd have had to guess.
  • USB-C CC resistors. Everyone mentions them, nobody explains why until you're sitting with a charger that won't power your board. 5.1 kΩ on both CC pins = power. Without them = nothing. Two days of my life went into figuring this out.
  • I had a floating GND island in my first layout that caused intermittent RF glitches under load. GND stitching vias every ~2 mm fixed it — now I add them by habit before I even think about routing signals.

This is a custom development board built around the ESP32-S3-MINI-1-N8 — Espressif's compact Wi-Fi and Bluetooth 5.0 module. The goal was straightforward: design something equivalent to a commercial dev board from scratch, understanding every part of it. It breaks out all usable GPIOs, adds an on-board temperature and humidity sensor, an addressable RGB LED, and powers from a single USB-C cable or 5V rail. 

The entire design was done in KiCad 9, from schematic capture through to manufacturing-ready Gerber files, targeting JLCPCB's 4-layer process with the JLC04161H-3313 stackup. The USB differential pair was analysed for impedance using IPC-2141 calculations matched to that specific stackup, and all design rules were verified clean before ordering.

This was completed as an independent project during second year Electrical and Electronic Engineering at the University of Western Australia. It was also my first multi-layer PCB — prior hands-on work had been breadboards and single-layer designs, so KiCad, manufacturing tolerances, and impedance-controlled routing were all learned from scratch alongside the design.

⚠ Note: The 3V3 header pin is a regulated output only — do not apply external voltage to it. The TLV75801 LDO has no back-drive protection; powering through 3V3 with USB disconnected will damage the IC. Power the board via USB-C only. See Rev 2 for a planned fix.

Design Process

Phase 1 — Schematic Capture
Component selection and schematic design in KiCad 9
Components were chosen from Espressif application notes and each IC's datasheet — the CC resistors took the most time to track down (see What I Learned above). Completed the full schematic: USB-C with CC pull-downs, TLV75801 LDO, ENS210 I²C sensor, WS2812B RGB LED, and GPIO breakout. ERC came back clean on the first pass.
Full schematic — KiCad 9 schematic editor
Phase 2 — Impedance, Constraints & Netclasses
IPC-2141 differential pair impedance for JLCPCB JLC04161H-3313 stackup
Used JLCPCB stackup JLC04161H-3313: PP prepreg 3313×1 with h = 0.0994 mm and Dk = 4.4. Applied IPC-2141 edge-coupled microstrip formula — the calculated target trace width for exactly 90 Ω differential is 0.142 mm (5.59 mil) at 0.15 mm spacing. The USB D± pair was routed at 0.15 mm (default netclass width), which is slightly wider than the target — giving an estimated ~88 Ω, well within USB 2.0 Full Speed tolerance of 90 Ω ±15%.
IPC-2141 impedance calculation — recalculated for JLCPCB stackup
Design constraints — JLCPCB manufacturing rules
Before routing, design rules were configured to match JLCPCB's JLC04161H-3313 stackup requirements: minimum trace width 0.15 mm (JLCPCB's manufacturing capability is 0.09 mm — a more conservative limit was set in KiCad), minimum via diameter 0.45 mm (drill 0.3 mm), hole-to-hole clearance 0.5 mm, copper-to-board-edge clearance 0.3 mm, and minimum annular ring 0.1 mm. Rules were applied as a KiCad DRC constraint file and a clean DRC pass was confirmed before routing began.
JLCPCB manufacturing constraints configured in KiCad design rules
Netclasses — power and signal net classification
Nets were grouped into custom netclasses before routing: PWR (VBUS, VCC, GND) assigned 0.3 mm minimum trace width to handle higher current paths; SIG (GPIO, SPI, I2C, UART) kept at default 0.15 mm. The USB differential pair (D+/D−) was routed at 0.15 mm width and 0.15 mm spacing using the default netclass — within USB 2.0 Full Speed tolerance.
Custom netclasses defined for power, signal, and USB differential pair
Phase 3 — Component Placement & 3D Verification
Placing components in the right order before touching a single trace
Worked through signal flow — USB-C first, then ESD protection, LDO, and the module last. Decoupling caps go right next to each IC's power pin, not just nearby.
3D model alignment and mechanical clearance review
Added STEP 3D models to all components. PTS810 buttons required X-rotation to 90°. Pin headers required Y-rotation 180° and Z-offset −1.5 mm for correct through-hole placement. Reviewed in KiCad 3D viewer before Gerber export.

Key Engineering Decisions

Native USB over USB-to-UART bridge
Uses the ESP32-S3 built-in USB Serial/JTAG controller via GPIO19 (D−) and GPIO20 (D+) instead of a CP2102N bridge. One fewer IC, lower BOM cost — serial and JTAG still work natively.
USB D± impedance — routed to JLCPCB JLC04161H-3313 stackup
The JLC04161H-3313 stackup publishes its prepreg parameters, which made the IPC-2141 calculation straightforward — no guessing at Dk. Routed at 0.15 mm, slightly above the 0.142 mm target, giving ~88 Ω — well inside the USB 2.0 Full Speed tolerance of 90 Ω ±15%. Full calculation walkthrough is in the Design Process section.
GPIO0, EN, and USB D± excluded from headers — replaced with power pins
GPIO0 is reserved for the BOOT button, EN for the RESET button, and GPIO19 (D−) / GPIO20 (D+) are routed directly to the USB-C connector — none of these are safe or useful to expose on a general-purpose header. The four positions freed up are replaced with additional power and ground pins: each header provides 3V3 and GND at the top (pins 1–2) and a second GND and 5V VBUS at the bottom (pins 21–22). This gives two ground references per header, which is practical for breadboard use and reduces the chance of floating grounds when connecting peripherals.
4-layer stackup with dedicated GND plane on L2
A solid GND plane directly under the signal layer is what makes impedance control and decent RF behaviour possible — the ESP32-S3 Wi-Fi/BT radio needs a clean ground reference, and a 2-layer board can't reliably provide either.
LDO package selection based on thermal analysis
TLV75801 WSON-6 selected over SOT-23: RθJA = 80.3°C/W vs 176.9°C/W. At 300mA load (P = 0.51W), WSON-6 gives only +41°C junction rise vs +90°C for SOT-23. Thermal pad soldered to GND copper pour.
LDO feedback resistors — R3/R4 set Vout to 3.3V
R3 (1MΩ) and R4 (200kΩ) form the TLV75801 output voltage feedback divider. The 1:5 ratio sets the regulated output to 3.3V. Values chosen to minimise quiescent current through the divider while staying within the LDO's feedback input impedance spec.

Future Improvements — Rev 2

LDO feedback divider — reduce resistor values in Rev 2
R3/R4 (1MΩ / 200kΩ) set Vout correctly but the high impedance increases sensitivity to PCB leakage. Rev 2 will scale down to 100kΩ / 20kΩ, maintaining the same output voltage while lowering source impedance and improving noise rejection.
WS2812B power supply — Rev 2 fix required
Standard WS2812B minimum VDD is 3.5V; the current 3.3V supply is out of spec. Rev 2 will add 5V power to the LED and a level shifter on the DIN line so the logic high exceeds the 0.7×VDD input threshold. Alternatively, swapping to a 3.3V-compatible variant like the WS2812B-V5 would eliminate the level shifter entirely — something to evaluate in Rev 2.
Footprint library consolidation
Rev 2 will move all custom footprints (ESP32-S3-MINI-1-N8, USB4105) into a project-local KiCad library. This eliminates the footprint mismatch warnings in DRC and makes the project self-contained — no dependency on my local library path.
3V3 pin back-drive protection + bidirectional power input — Rev 2
The TLV75801 has no reverse current protection on its output — powering through the 3V3 header pin back-drives the LDO and will damage it. Rev 2 will add a series Schottky diode or ideal diode load switch, which blocks reverse current and makes it safe to power the board from an external 3.3V supply without USB-C.
Upgrade path — ESP32-S3-MINI-1-N8R8 (PSRAM variant)
Same pinout and footprint as the current module but adds 8MB PSRAM — no PCB changes needed. Worth the swap for anything involving display framebuffers, audio buffers, or memory-intensive applications.
